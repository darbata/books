# README

Learning project.

Implementing the following features:

As a visitor, I can create a user account with a name and email.
As a user, I can add a book to my library with a title and author, plus optional details like genre and page count.
As a user, I can see a list of all the books in my library.
As a user, I can view the details of a single book.
As a user, I can edit a book’s details.
As a user, I can remove a book from my library.
As a user, I can only see and change my own books, not other users’ books.
As a user, I can mark whether I own a book.
As a user, I can set a reading status on a book: want to read, reading, read, or abandoned.
As a user, I can rate a book I’ve read (1–5) and add a short note about it.
As a user, I can filter my library by reading status or ownership.
As a user, I can export my library as a JSON summary showing what I’ve read (with ratings and notes), what I’m reading, and what I want to read
As a user, I can search my library by title or author.
As a user, I can see simple stats, like how many books I’ve read and my average rating.
